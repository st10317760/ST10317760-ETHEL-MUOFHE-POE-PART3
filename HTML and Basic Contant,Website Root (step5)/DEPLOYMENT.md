# Publishing checklist (GitHub Pages)
1. Create or open your lecturer-approved GitHub repository.
2. Upload the contents of this folder to the repository root (so `index.html` is at the root).
3. Commit with a descriptive message such as `Add Part 3 JavaScript, forms and SEO updates`.
4. Push/commit changes to GitHub.
5. In repository Settings → Pages, select the correct branch and root folder, then save.
6. Wait for GitHub Pages to publish and open the generated URL.
7. Replace `https://example.com` in `robots.txt` and `sitemap.xml` with the published domain and commit again.
8. Test the published site on desktop and mobile. Test forms with an email application configured.
9. Submit the actual repository URL to the learning platform. Do not submit a guessed URL.
